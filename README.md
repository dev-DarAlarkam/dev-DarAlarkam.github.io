# dev-DarAlarkam.github.io

A small website for Dar Al-Arqam that provides quick tools for managing certificates, announcements, and important links.

## Pages

- `index.html` is the home menu.
- `certificates.html` contains the memorization certificate generator.
- `completion-certificates.html` contains the completion and grades generators.
- `rooms-program.html`, `resources.html`, `anthem.html`, and `announcements.html` are standalone feature pages.

Shared site styles are in `css/styles.css`; page-specific styles are in separate files under `css/`.
Images, fonts, logos, and audio files are organized under `assets/`, with MP3 files in `assets/mp3/`.
Run the site through a local HTTP server when testing certificate previews and exports, because the generators fetch their template images.
